# AI Interview Prep Assistant (Backend)

Backend service for an AI Interview Prep Assistant built with Node.js + Express and Google Gemini API (ES Modules, stateless architecture).

For detailed documentation, endpoints, setup guide, and sample `curl` commands, see [server/README.md](file:///c:/Users/raisn/Desktop/rag/server/README.md).

## Quick Start

```bash
cd server
npm install
cp .env.example .env
# Edit .env and set your GEMINI_API_KEY
npm run dev
```
